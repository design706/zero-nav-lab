# Coach photos

Drop coach portrait photos here, named by coach key:

- `jenna.jpg`   — Jenna (Warm)
- `ian.jpg`     — Ian (Motivational)
- `jessica.jpg` — Jessica (Strategic)
- `navi.jpg`    — Navi (Direct)

Square-ish portraits work best (they're rendered as rounded/cover). If a file is
missing, the UI falls back to the coloured initial avatar automatically.
